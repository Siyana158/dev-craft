# Security policy

## Reporting a vulnerability

Please report security issues privately. If GitHub's **Report a vulnerability** option is available in the repository's Security tab, use it. Include the affected file or feature, impact, and steps to reproduce, while avoiding real user data and live credentials.

If private reporting is unavailable, open a minimal issue asking the maintainers for a private contact path. Do not include exploit details, secrets, or personal data in the public issue.

## Scope

This policy covers the dev-craft repository, its scripts, examples, and documented installation flows. Please do not test against systems or accounts you do not own.
