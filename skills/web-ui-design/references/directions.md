# Directions

Pick ONE direction per page, from the brief. State the choice and the reason in the brief card. This exists to stop every page converging on the same recipe (oversized type, flat colour blocks, a card grid, a big name in the footer).

**Variety guard.** If the previous page you built in this project used a direction, pick a different one unless the brief or existing brand clearly demands it. If two directions fit, choose the less familiar one. A direction sets the structure, not only the colours.

| Direction | Fits | Palette and type | Structural signature | Motion |
|---|---|---|---|---|
| **Editorial bold** | food, craft, culture, local shops | One flat ground, one ink, one accent; one heavy grotesk or a serif at very large sizes | Few words, huge type, flat colour fields, asymmetric 12-column grid, objects shown as printed artefacts | Staggered rises, slow hover lifts |
| **Modern product (dark)** | software, finance, AI, developer tools | Near-black ground, soft glow, one mint/blue accent pair; a clean geometric sans | Floating pill nav, centred hero, **product mockup built in HTML**, bento grid, spotlight hover, live simulator | Counting numbers, draw-on lines, tilt-to-flat on scroll |
| **Soft light** | health, wellness, education, family services | Warm-white or pale tint ground, rounded shapes, two muted tones, a friendly humanist sans | Large radii, stacked soft panels, generous space, illustrated or photographed people | Gentle fades, no sharp easing |
| **Technical grid** | infrastructure, data, docs, hardware | Light or dark neutral, monospace for data only, one signal colour | Visible structure, dense information, tables, code or spec blocks, comparison views | Minimal; state changes and cursor feedback |
| **Playful** | kids, games, community, apps for young audiences | Saturated flat colours, chunky rounded type, bold shapes | Overlapping stickers, tilted elements, big buttons, oversized icons | Springy overshoot, hover wobble |
| **Quiet luxury** | hospitality, jewellery, architecture, boutique services | Deep neutral or paper tone, a refined serif with a restrained sans, thin spacing | Wide margins, slow full-bleed imagery, small centred text, very few elements per screen | Slow fades, long durations |
| **Raw / utilitarian** | studios, zines, activism, indie tools | Black, white, one harsh colour; system-like or condensed type | Rigid grid, visible borders, plain lists, no decoration | None or abrupt |

## Using a direction

1. Choose from the table using audience and subject, not personal habit.
2. Write the direction and one sentence of reasoning in the brief card.
3. Apply its palette and type to the tokens file (stage 3) and its signature to the weight map (stage 4).
4. Do not mix two directions on one page; borrow single details only if they serve the subject.
5. In the report, name the direction used.

## Checking variety

Before finishing, compare against the last page you built: do the hero layout, section order, and card style differ? If the answer is "no" for two or more of those, revisit the choice.
