Storage you can reason about.

Stratum is an append-only store with a plain SQL interface, a documented on-disk format and a storage cost you can calculate before you deploy.

01 / SPEC

What it is, exactly.

No marketing words in this table. If a limit is not listed, it is not promised.

Write modelAppend-only. Rows are immutable once written; late data up to 24h is accepted.
Query languageSQL subset: SELECT, WHERE, GROUP BY, bucket(), joins on host tags. No updates or deletes.
Storage formatColumnar segments, one per hour, compressed with zstd. Format is documented and stable across 0.x minor versions.
DurabilityWrite-ahead log, fsync every 100ms by default; configurable down to every write.
RetentionPer table, by age. Whole segments are dropped; no background compaction of old data.
ClusteringNot yet. One node, with hourly snapshots to object storage. Replication is on the roadmap, not in this release.
FootprintSingle static binary, about 18 MB. Runs on Linux and macOS, x86-64 and ARM64.
02 / DESIGN

One path in, one path out.

Writes go to a log, then to hourly segments. Queries read only the segments and columns they need.
